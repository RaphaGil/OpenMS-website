Build your own pipelines using our ecosystem

  • C++ library

    OpenMS-lib

    Reusable C++ algorithms and data structures for mass spectrometry software. Ships with The OpenMS Pipeline (TOPP) command line tools for mass spectrometry analysis.

    Learn more→
  • Python

    pyOpenMS

    Python bindings to OpenMS-lib. Write custom analysis scripts and integrate OpenMS into Python workflows.

    Learn more→
  • Web apps

    OpenMS-Web apps

    Web interface template for OpenMS pipelines. Deploy custom analysis tools as interactive web apps without frontend development.

    Learn more→
  • Visualization

    pyopenms_viz

    Visualization library for mass spectrometry data. Create interactive and static plots directly from Python dataframes.

    Learn more→
