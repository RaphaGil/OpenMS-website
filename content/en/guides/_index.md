What each application does, how to install it, and how to run it on your data.

| Guide | What it is for |
|-------|----------------|
| [NuXL](/guides/nuxl/) | Protein-RNA and DNA cross-linking |
| [FLASHDeconv](/guides/flashdeconv/) | Ultra-fast MS1/MS2 deconvolution for top-down proteomics |
| [MHCquant](/guides/mhcquant/) | Quantification and identification workflow for MHC peptides |
| [OpenPepXL](/guides/openpepxl/) | Protein-protein cross-linking |
| [EPIFANY](/guides/epifany/) | Efficient Bayesian protein inference |
| [MetaProSIP](/guides/metaprosip/) | Stable isotope probing |

More OpenMS tools are described in the [TOPP documentation](https://openms.de/doxygen/nightly/html/TOPP_documentation.html). Ready-to-use apps are on the [Featured Apps](/featured-apps/) page.
